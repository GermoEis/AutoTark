Auto24 import AutoTark-sse

  1. Ava Chrome'is või Edge'is chrome://extensions.
  2. Lülita sisse Developer mode.
  3. Vali Load unpacked ja vali projekti extension kaust.
  4. Ava Auto24 kuulutus.
  5. Vajuta kuulutuse paremas alanurgas nuppu Impordi AutoTark-sse.

Laiendus loeb ainult sinu avatud Auto24 lehelt nähtavaid autoandmeid ja avab need AutoTark rakenduses.
