# AutoTark Auto24 import

1. Ava Chrome'is või Edge'is `chrome://extensions`.
2. Lülita sisse **Developer mode**.
3. Vali **Load unpacked** ja vali see `extension` kaust.
4. Ava Auto24 kuulutus. Lehe paremasse alumisse nurka ilmub **Impordi AutoTark-sse**.

Laiendus loeb ainult avatud Auto24 lehelt nähtavaid autoandmeid ja avab need lokaalses AutoTark rakenduses. Ta ei saada Auto24 andmeid kõrvalisele serverile.
